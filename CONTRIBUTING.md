# Contributing to TimeDiff

Thanks for your interest in improving TimeDiff.

## How to contribute

1. Fork the repository.
2. Create a feature branch from the default branch.
3. Make a focused change with tests where relevant.
4. Run the project checks locally.
5. Open a pull request with a clear summary.

## Local development

```bash
npm install
npm run dev
npm test
npm run build
```

## Code style

- Keep the code simple and readable.
- Maintain the minimal black-and-white app aesthetic.
- Prefer small, well-tested utility functions.
- Document complex logic when it is not obvious.

## Reporting issues

Please open an issue with:

- a clear description
- steps to reproduce
- expected behavior
- actual behavior
- browser or environment details if relevant

## Code of conduct

Be respectful, constructive, and collaborative. We aim to keep the project welcoming and professional.
