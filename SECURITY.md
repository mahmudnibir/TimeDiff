# Security Policy

## Supported versions

The project is currently maintained in its main branch. Please report any issue you discover as soon as possible.

## Reporting a vulnerability

Please do not disclose a security issue publicly before it has been addressed.

Open a private security report through the repository's security advisories or contact the maintainer directly through the GitHub profile associated with the repository.

Include:

- a summary of the vulnerability
- affected code or routes
- reproducible steps
- potential impact
- suggested fix if available

We will review reports promptly and coordinate a fix.
